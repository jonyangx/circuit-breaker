# Ops / 运维人员专用目录

> 本目录用于存放**生产环境出现过的事故、处理与排查方式**，是运维团队的应急知识库与经验沉淀区。

## 目录用途
记录生产环境真实发生的故障、处理过程和排查手段，沉淀可复用的应急预案与运维经验，缩短未来同类问题的 MTTR。

## 适合存放的内容
- **事故复盘（Postmortem）**：时间线、影响范围、根因、处理过程、改进项
- **排查手册（Runbook）**：常见故障的排查步骤、定位命令、关键日志位置
- **应急预案**：高风险场景的预案、回滚步骤、降级方案
- **监控与告警说明**：关键指标、告警含义、阈值与处置建议

## 事故复盘建议结构
现象 / 影响范围 / 时间线 / 根因 / 排查过程 / 处理方式 / 改进项
